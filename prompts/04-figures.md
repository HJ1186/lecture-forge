# 04 · 配图：从视频里抠，或者自己画

讲义里"图都是文字描述"是最劝退的。规则很简单：**每一处需要想象的地方，给一张图。**

## 三种图，优先级从高到低

1. **原片截图**（最可信）——老师划重点、写公式、画电路的那一帧。
2. **教材/原文件里的图**——如果是 PDF，直接按页裁（比截图清楚）。
3. **自己画**——原片里根本没有这张图（比如你自己编的例题）时，用脚本画一张干净的。

## 从视频抠图

```bash
python -m lecture_forge slides work/video.mp4 -o work/slides --min-interval 8 --threshold 0.004
```

- 屏幕录制的课，通常"一分钟一页幻灯片"，`--min-interval 8` 就够了；动画多就提到 12–15。
- 抽出来是先按亮度裁过、再 2× 放大的。**先拼一张缩略图总览**（把 20–30 张缩到 360px 拼成图），
  一次性看完挑出要用的，再逐张打开确认文字能看清。
- 视频本身分辨率低（比如 640×400）时，宁可**少放图**也不要放糊的图；糊图不如自己画。

## 裁得更紧（当自动裁切失败时）

自动裁切靠"找最亮的大矩形"，遇到桌面背景、PPT 窗口没最大化就会失败。这时：
用预览确认像素范围，按固定坐标裁一次（`av` 取帧 + `PIL.crop`），再放大 2.5–3×、轻度锐化。
输出 PNG 用 `quantize(colors=64)` 存，体积通常降到 1/3，小字仍然清楚。

## 自己画图

- 用脚本画（PIL / matplotlib 都行），**保存脚本**，方便以后改参数重画。
- 画布 1100×620 左右、字号 ≥20px、连线留白充足。
- 元件符号用简单几何（矩形=电阻、圆圈=电源），符号旁一定标名字和数值。
- 同一份讲义里**风格统一**：线的粗细、颜色、标签位置保持一致。

## 图注格式（固定）

```markdown
![一句话说明这张图在讲什么](img/xxx.png)

*▲ 视频 12:50：老师在这里把串联合并讲完，正好对应上面的 n=4、b=6*
```

- 方括号里写"这张图在讲什么"，不要写"图 3"。
- 图注以 `*▲` 开头，渲染出来是居中的灰色小字。
- 引用了别人的图（教材、别人的课件），**在图注里写清出处**；不能确定授权就不要放进公开仓库。

## 交付前检查

- [ ] 讲义里每张图的文件都真的存在（`build` 时不会报错，但页面会空一块）
- [ ] 没有一张图是"糊到看不清"的
- [ ] 图注都写了 `视频 mm:ss` 或 `自绘`
- [ ] 公开仓库里没有版权不明的大图
